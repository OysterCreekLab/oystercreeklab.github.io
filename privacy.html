Privacy Policy: Oyster Creek Dashboard

Effective 2026-11-18.

What it reads

With the account owner's permission, the Dashboard reads calendar events from Google Calendar. It uses one scope, calendar.events.readonly. It cannot create, change or delete events.

Where the data goes

  • Events are fetched by a program on the owner's own PC and shown on that PC's screen.
  • The sign-in token is stored on that PC, encrypted for the owner's Windows user account.
  • No calendar data is sent to any server other than Google's, sold, shared, or used for advertising.
  • The latest events are kept on the PC only so the screen can show them; older copies are replaced on each refresh.

Google API Services User Data Policy

The Dashboard's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove the Dashboard's access at any time from Google Account permissions.
